# GithubCLI
GithubCLI is a simple CLI tool to fetch github users data and repository using the public github api.

# Installation

```
git clone https://github.com/darknessmalware/GithubCLI.git
cd GithubCLI
go get .
```

# Build 

```

go build main.go

```

# Usage 

```
./main -user <username> 
```
